# 时间与样本估算规则

## 总原则

- 只使用输入中明示的数字；缺什么就写“不确定/信息不足”，不补外部经验值。
- 每次计算都输出 `formula`，让人工能按定位复算。
- 等待、周转、设备占用、人工操作分开列；并行步骤不自动合并。

## 时间

1. 从步骤行提取数字 + 单位：`h/小时`、`min/分钟`、`d/天`，统一换算为小时。
2. 按关键词分相：
   - 设备占用：设备/仪器/采集/离心/色谱/HPLC/PCR/测序/运行；
   - 等待周期：等待/孵育/过夜/平衡/培养/静置；
   - 其余为人工操作。
3. 合计：`total = Σ 分项`，输出 `2 + 1.5 + 0.5 = 4 h` 形式。
4. 跳过“总时长/时间窗/判读标准”行，避免把声明值或阈值重复计入分项。
5. 若另有声明总时长且与分项差 > 0.1 h，记 `arithmetic_mismatch` 冲突。
6. 与 `time_window_h/time_budget_h/max_hours/...` 比较；无时间窗记不确定，不判满足。

## 样本

1. 只在明示时计算：
   `required = 样本数 × 组数 × 重复数`；未写的组数/重复数按 1 处理，并在公式中显示。
2. 可得量来自样本库存行（`category=样本` 或名称含样本/血清/血浆/aliquot）的 `quantity` 合计。
3. 比较：
   - `available ≥ required` → sufficient；
   - 不足且缺口 ≤ 50% → conflict / major；
   - 不足且缺口 > 50% → conflict / blocker；
   - 需求或可得量缺失 → uncertain，禁止估算。
4. 若案例直接给 `required/available`，优先用案例值，并与计算值交叉核对。

## 参数

1. 参数名做同义归一：柱温/column_temp、流速/flow_rate、进样量/injection_volume、pH 等。
2. 单位先换算再比较：时间、体积、质量、温度；无法换算时记 `unit_inconsistent`，不得静默忽略。
3. 上下限、允许值列表都视为有限参数域；无参数域记 uncertain。

## 资源

- 状态四类：已具备 / 可外协 / 需采购 / 不具备；无法判断记未知。
- 方案点名但清单无对应行，记 `unmatched_resource`，不得默认已具备。
- 需采购/可外协必须给出到位时间早于开工时间的条件。
