# 基准报告：实验方案审查技能 vs 朴素关键词基线

本报告由 `bench/run_bench.py` 生成，纯标准库、离线、确定性；不含时间戳与绝对路径。

## 1. 对照协议

- 输入：`bench/cases/<name>/{case.json,protocol.md,inventory.csv}`。
- 金标准：`bench/gold/<name>.json`，每个案例只植入一个可由原文/清单/参数域唯一判定的缺口。
- 技能调用：`python scripts/run_skill.py --input bench/cases/<name> --work <tmp>/work --out <tmp>`。
- 对照条件：同一案例、同一输入文件；技能与基线各跑一次，评价只读 `result.json.findings`。
- 基线：只在 `protocol.md` 中按固定关键词切句，命中句直接当作 finding，不核对库存、参数域或伦理，结论恒为“可行”。

## 2. 汇总指标

| 指标 | 技能 | 基线 | 差值（技能-基线） |
|---|---:|---:|---:|
| finding 类别召回 | 1.0 | 0.0 | 1.0 |
| finding 类别精确 | 1.0 | 0.0 | 1.0 |
| 结论一致性 | 1.0 | 0.0 | 1.0 |
| 可验证定位条目数 | 3 | 0 | 3 |
| 未解决缺口数 | 0 | 3 | -3 |

汇总口径：按案例对“finding 类别集合”计 TP/FP/FN；精确率在无预测且存在期望缺口时记 0；可验证定位条目数只统计命中类别的 finding 中 `evidence.verified=true` 的条目。

## 4. 基线定义

- 关键词：`缺失、未提供、不设、未设、未附、超过`。
- 切句：按 `。！？；;` 与换行切分，保留命中句原文。
- 类别：按句内关键词做一次朴素映射（伦理/对照/样本/参数/设备/材料/时间/风险/假设），不读取 `inventory.csv`、`case.json` 的参数域或伦理字段。
- 定位：不产生可回读的 locator/quote，故可验证定位条目数恒为 0。
- 结论：不使用检查项计数，恒输出“可行”。

## 5. 复现

```
python bench/run_bench.py
```

## 6. 已知边界

- 案例为合成材料，只用于验证“可定位判定 + 公平对照”，不代表真实实验方案。
- 基线故意不实现库存、参数域、伦理核对，不能外推为其他工具的能力上限。
- 指标按类别集合计，不评价同类别内多条 finding 的措辞质量；措辞质量需人工复核。
- 技能结论必须由检查项计数规则唯一决定；若案例出现歧义，应修案例而不是改金标准。
